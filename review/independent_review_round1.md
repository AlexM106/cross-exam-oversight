# Independent review: oversight pilot

Reviewer stance: skeptical, did not write the work. Every number in all 12 memos and keys was recomputed in Python. Tests were run (`python -m pytest -q`: 7 passed). No API calls were made.

## 1. Verdict

Ready with fixes. Not ready to publish as is. The pipeline works (tests pass, mock run completes, I found zero answer-key leakage into any judge, critic, defender or author prompt), 10 of 12 cases have an arithmetic-clean, real, single planted error, and no memo has a wrong calculation other than the intended one. But there are two things a PhD water resources reader will catch immediately. (1) LIT-02 contains an unintended second error: the TCE retardation claim (R < 1.05 at foc = 0.0003) is wrong by a wide margin (R is about 1.2 to 1.36), and the key says the rest is fine. (2) Control FH-04 contains a genuine analytical flaw (storm frequency classified from a single 15-minute duration) plus a technical misstatement ("would surcharge" at 21.4 cfs when open-channel gravity capacity peaks near 21.8 cfs). A flawed control corrupts the false-alarm metric. Beyond those, four cases have secondary issues that could let a judge legitimately find a real but "unplanted" flaw and be scored wrong. The code needs fail-fast and per-trial error handling before a 144-trial live run, and the planned statistics treat 30 correlated trials as independent. With n = 10 error cases and 2 controls, results must be reported as descriptive, per case.
